# Annonce de naissance — Projet portfolio

Une landing page responsive inspirée d'une annonce de naissance. Cette version est anonymisée afin de pouvoir être publiée dans un portfolio public.

## Fonctionnalités

- Compteur de démonstration en JavaScript, mis à jour chaque seconde.
- Photo de bébé optimisée et intégrée à la page.
- Mise en page responsive, pensée pour mobile, tablette et ordinateur.
- Navigation clavier visible et respect du réglage « réduire les animations ».
- Aucune API externe, aucun formulaire et aucune donnée personnelle exposée.

## Technologies

- HTML5
- CSS3
- JavaScript vanilla

## Lancer le projet

Ce projet ne nécessite ni PHP, ni Node.js, ni base de données.

1. Ouvrez le dossier dans VS Code.
2. Ouvrez `index.html` dans un navigateur, ou utilisez l’extension Live Server si elle est installée.
3. Le compteur de démonstration se met à jour automatiquement chaque seconde.

## Déploiement

Comme la page est entièrement statique, elle peut être publiée telle quelle sur GitHub Pages, Netlify ou Vercel. Aucune configuration serveur n’est nécessaire.

## Vérification manuelle

- Vérifier l’affichage sur mobile et ordinateur.
- Vérifier que les jours, heures, minutes et secondes progressent.
- Tester la navigation au clavier avec la touche `Tab`.
